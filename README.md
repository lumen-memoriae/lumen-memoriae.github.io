# Our Shelf — сайт полки

3D-полка с рамками и любимыми вещами (как в исходном макете `Our Shelf.html`), разложенная в нормальную структуру сайта, плюс кнопка сверху:

**добавить рамку** (в записке у каждой рамки есть «изменить» и «удалить») — фото, подпись, текст записки и вид рамки (дерево, золото, чёрная, белая). Новые рамки сначала занимают места пустых «будут еще, добавим жи ес», потом автоматически добавляются новые полки (на компьютере чередуются полки на 3 и 2 рамки, на телефоне по 2). Когда полок становится много, страницу можно листать колёсиком или пальцем.

Всё, что было в макете, работает как раньше: клик по рамке приближает её и показывает записку, стрелки и Esc, параллакс, гирлянда, раскладка под телефон.

## Структура

```
index.html            разметка страницы
css/style.css         стили
js/vendor/three.min.js  three.js r128 (лежит локально, CDN не нужен)
js/content.js         содержимое полки по умолчанию (рамки, фото, предметы)
js/util.js            помощники и процедурные текстуры
js/objects.js         3D-модели предметов и их настройки
js/store.js           сохранение добавленных рамок в браузере (IndexedDB)
js/app.js             сцена, раскладка, зум, формы добавления
```

Сборка не нужна: это обычные статические файлы.

## Как открыть

- Просто открыть `index.html` двойным щелчком: работает (фото лежат внутри `content.js`).
- Или выложить папку на любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.

## Важно про сохранение

То, что добавлено через кнопки, сохраняется **в этом браузере на этом устройстве**. Другие люди этого не увидят, пока вы не обновите сайт:

1. Добавьте рамки у себя.
2. Меню «⋯» → **сохранить полку в файл**, скачается `content.js`.
3. Замените им `js/content.js` на хостинге. Теперь эту полку видят все.

«⋯ → вернуть полку как было» стирает всё добавленное в этом браузере.

Если нужно, чтобы добавленное сразу видели все без замены файла, понадобится небольшой сервер с базой. Его можно добавить отдельно.

## Как добавить предмет на полку вручную

Предметы описаны в `js/content.js`, в списке `objects`. Чтобы поставить ещё один, добавьте строку, например:

```js
{ id:'o-car2', type:'car', params:{ color:'#b3242e' } },
```

Доступные типы и их настройки (`params`) перечислены в `OBJECT_TYPES` в `js/objects.js`: cat, records, console, pack, vodka, geode, car, rackets, а также books, plant, candle. Порядок в списке задаёт порядок на полках; новые предметы встают после существующих.
