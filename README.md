# Our Shelf — сайт полки

3D-полка с рамками и любимыми вещами (как в исходном макете `Our Shelf.html`), разложенная в нормальную структуру сайта, плюс кнопка сверху:

**добавить рамку** (в записке у каждой рамки есть «изменить») — фото, подпись, текст записки и вид рамки (дерево, золото, чёрная, белая). Новые рамки сначала занимают места пустых «будут еще, добавим жи ес», потом автоматически добавляются новые полки (на компьютере чередуются полки на 3 и 2 рамки, на телефоне по 2). Когда полок становится много, страницу можно листать колёсиком или пальцем.

Всё, что было в макете, работает как раньше: клик по рамке приближает её и показывает записку, стрелки и Esc, параллакс, гирлянда, раскладка под телефон.

## Структура

```
index.html            разметка страницы
css/style.css         стили
js/vendor/three.min.js  three.js r128 (лежит локально, CDN не нужен)
js/content.js         содержимое полки по умолчанию (рамки, фото, предметы)
js/util.js            помощники и процедурные текстуры
js/objects.js         3D-модели предметов и их настройки
js/store.js           запасное сохранение в браузере (IndexedDB)
js/cloud.js           общая полка через Firebase
js/firebase-config.js настройки проекта Firebase
firestore.rules       правила доступа к базе
js/app.js             сцена, раскладка, зум, формы добавления
```

Сборка не нужна: это обычные статические файлы.

## Как открыть

- Просто открыть `index.html` двойным щелчком: работает (фото лежат внутри `content.js`).
- Или выложить папку на любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.

## Общая полка (Firebase)

Рамки, которые добавляют посетители, хранятся в Firebase Firestore (проект `lumen-memoriae`) и видны всем сразу.

- Любой посетитель может повесить рамку. Изменить её может только он сам (с того же устройства) и хозяин.
- Хозяин входит через `https://lumen-memoriae.github.io/#admin` → «⋯» → «войти как хозяин» (почта и пароль из Firebase → Authentication → Users). После входа можно изменить или удалить любую рамку, включая исходные.
- Настройки подключения: `js/firebase-config.js`. Правила доступа: `firestore.rules`, их нужно вставить в Firebase → Firestore Database → Rules и заменить `ВАША_ПОЧТА` на почту хозяина.
- В Firebase → Authentication → Sign-in method должны быть включены **Anonymous** и **Email/Password**.
- Фото перед загрузкой сжимаются до ~1 МБ (лимит документа Firestore).

Если Firebase недоступен, сайт работает в старом режиме: добавленное сохраняется только в этом браузере, а «⋯ → сохранить полку в файл» собирает `js/content.js`.

## Как добавить предмет на полку вручную

Предметы описаны в `js/content.js`, в списке `objects`. Чтобы поставить ещё один, добавьте строку, например:

```js
{ id:'o-car2', type:'car', params:{ color:'#b3242e' } },
```

Доступные типы и их настройки (`params`) перечислены в `OBJECT_TYPES` в `js/objects.js`: cat, records, console, pack, vodka, geode, car, rackets, а также books, plant, candle. Порядок в списке задаёт порядок на полках; новые предметы встают после существующих.
